# NOVA

**NOVA** is a mobile digital ecosystem — AI, games, social, creation, marketplace and mystery in one app.

## Stack
- Expo + React Native
- JavaScript
- Expo Vector Icons

## Run locally
```bash
npm install
npx expo start
```

Open with Expo Go, or use `npm run ios` / `npm run android`.

## Current build
- Mobile shell + bottom navigation
- Home dashboard
- NOVA AI workspace UI
- Games hub
- Social activity UI
- Creator hub
- Settings
- GitHub Actions validation

## Roadmap
- Supabase authentication + profiles
- Realtime chat and communities
- AI API + agents
- Game catalog and leaderboards
- Creator projects + cloud storage
- Marketplace
- Mystery/ARG layer
- Push notifications
- App Store + Google Play builds

NOVA is intentionally modular so new systems can be added without replacing the app shell.
